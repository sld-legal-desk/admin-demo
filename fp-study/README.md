# FP合格ナビ — FP技能検定 学習アプリ

ファイナンシャル・プランニング技能検定（FP技能検定 3級・2級）の合格を目指すための、
ブラウザだけで動く学習アプリです。ビルド不要・React（CDN）+ Babel standalone 構成。

## 主な機能

- **ホーム / ダッシュボード** … 総合正答率・学習済み問題数・連続学習日数・分野別の習熟度を一覧
- **問題演習** … 分野（6分野）・形式（○×／三択）・問題数を選んで演習。即時採点＋解説
- **模擬試験** … 全分野からランダム10問を出題。所要時間を計測し、正答率60%で合格判定
- **苦手復習** … 正解より間違いが多い問題だけを集めて集中復習
- **学習統計** … 分野別の正答率、のべ解答数、学習日数などを可視化
- **進捗の自動保存** … `localStorage` に学習履歴を保存（リセット可能）
- **レスポンシブ対応** … PCはヘッダーナビ、スマホは下部タブナビに自動切替

## 使い方

`fp-study/index.html` をブラウザで開くだけです。ローカルで開く場合は、
モジュール読み込みのため簡易サーバー経由を推奨します。

```bash
cd fp-study
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## ファイル構成

- `index.html` … エントリーポイント（CDN読み込み・JSXランタイム設定）
- `questions.js` … 問題バンク（分野定義＋全問題データ）。問題の追加・編集はここ
- `app.jsx` … アプリ本体（UI・出題エンジン・統計・永続化）

## 問題の追加方法

`questions.js` の `FP_QUESTIONS` 配列に追記します。

```js
{ id:"A12", cat:"A", level:3, type:"ox",
  q:"問題文…", answer:true, explain:"解説…" }

{ id:"C11", cat:"C", level:2, type:"mc",
  q:"問題文…", choices:["選択肢A","選択肢B","選択肢C"], answer:1, explain:"解説…" }
```

- `cat` … 分野記号（A〜F）
- `type` … `"ox"`（○×）または `"mc"`（三択）
- `answer` … ○×は `true`/`false`、三択は正解の選択肢インデックス（0始まり）
- `level` … `3`＝3級相当 / `2`＝2級相当（表示用）

## 注意

学習用に作成したコンテンツです。税制・社会保険・金融などの数値や制度は
法改正で変わるため、本番対策では必ず最新の公式情報をご確認ください。

## 技術メモ

現行の `@babel/standalone` は preset-react の JSX 自動ランタイム
（`import "react/jsx-runtime"`）を既定とします。UMD の React グローバルを使う
本構成ではこれが `Cannot use import statement` を引き起こすため、`index.html` で
クラシックランタイムのプリセット（`react-classic`）を登録して明示指定しています。
